# CrossApp
Наскрізний проєкт з крос-платформного програмування.

Предметна область: Сервісний центр.
Сутності: Device, Customer, RepairOrder, Technician.
Призначення: облік заявок на ремонт техніки клієнтів.

## Запуск
dotnet build
dotnet run --project src/Cli

## Середовище
.NET SDK 8.0, macOS

## Порівняння режимів публікації

| RID | Режим | Розмір publish | Потрібен runtime |
| :--- | :--- | :--- | :--- |
| osx-arm64 | self-contained | ~70 МБ (вкажіть своє число) | ні |
| osx-arm64 | framework-dependent | ~0.2 МБ (вкажіть своє число) | так (.NET 8) |

- **Self-contained**: пакує середовище виконання .NET разом із застосунком; запускається будь-де без налаштування, але займає багато місця.
- **Framework-dependent**: містить тільки dll-файли самої програми; має мінімальний розмір, але вимагає попередньо встановленого .NET відповідної версії.
